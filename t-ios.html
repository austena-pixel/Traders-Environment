How the Sync Works

MT5 sends account state, positions and deal history to a secure Supabase Edge Function.

Deriv MT5 → TE Bridge EA → Supabase Edge Function → TE Database → Realtime UI
The bridge contains no order placement, position modification, or close-trade commands. It is designed only to read MT5 account/trade information and send it to T·IOS.
