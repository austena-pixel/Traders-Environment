# T-IOS Sidebar Toggle Position — Yellow Box Revision

The desktop sidebar control is repositioned to match the user's marked yellow-box location in the upper brand area.

## Open sidebar
- control size: 40 × 48 px;
- top position: 66 px from the top of T-IOS;
- right offset: -14 px;
- approximately 65% of the control remains inside the sidebar and 35% protrudes past the divider;
- additional brand-side padding prevents the control from touching the nearby T-IOS text.

## Closed sidebar
- reopen control uses the same 66 px top position;
- it sits 12 px away from the browser's left edge instead of touching the viewport edge;
- the page heading gains enough left padding to avoid overlap.

The existing press and slide animations remain active.

No trading, navigation, intelligence, or data logic changed.
