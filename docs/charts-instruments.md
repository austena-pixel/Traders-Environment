# Instruments in the Charts sidebar

The **Instruments** button beside the Charts sidebar title replaces chart settings with the existing Playbook, Rules and Psychological Reflection recording workspace. **Chart settings** returns to the settings view. The chart grid and optional public quote remain running while switching sidebar views.

Choose the trade and saved instrument, use its conditions, choices, written responses or score fields, then choose its existing **Save** button. Session, daily, weekly and monthly Rules use their existing period selectors and are saved on the current device, with an explicit status. Trade responses use the existing authenticated Supabase execution review/check records. The score rules are unchanged; written reflections and saved form state remain separate from quantitative compliance evidence.

There is one recording workspace and one save path. Charts temporarily moves the original DOM nodes into its independently scrolling rail, retaining their IDs and handlers. Returning to settings or leaving Charts restores them to Execution Quality. Existing draft capture/restore preserves unsaved responses across instrument, trade and view changes. Settings stay in the same DOM while the Instruments view is open. Opening market evidence returns to settings. Verification polling pauses while Instruments is displayed.

The adapter loads only on demand. Cancelled or failed module loads cannot attach a late form after navigation or a session change; errors offer Retry and retain the original workspace. Reset restores the original nodes and clears session-specific form values without writing or deleting saved records. No database, MT5 bridge, journal entry, screenshot, instrument definition or scoring changes are introduced.

The Charts recording view now uses plain checklist rows: a small 14 px square beside each label, without colored condition cards or large controls. Optional comments remain available in compact fields. Choice controls such as Balance / Imbalance retain their original single-choice radio semantics, including selecting again to clear; the square is only their visual presentation. Their labels, values, IDs, saved state and scoring stay unchanged. Reference pictures and written/score responses remain available. These style overrides apply only inside the Charts recording form; Execution Quality and saved instrument documents keep their existing presentation.
