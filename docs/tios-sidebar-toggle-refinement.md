# T-IOS Sidebar Toggle Visual Refinement

The desktop sidebar collapse control is now vertically centered on the sidebar's right divider rather than sitting in the brand header.

## Interaction

- The collapse control straddles the sidebar divider slightly.
- It uses a blue-accented vertical pill shape with border glow and depth.
- Hover shifts the control outward slightly.
- Pressing it scales the control down briefly for tactile feedback.
- The reopen control mirrors the same styling at the left edge of the viewport when the sidebar is collapsed.
- The brand header no longer reserves horizontal space for the old top-positioned button.

No sidebar state logic, page behavior, trading logic, or intelligence behavior changed.
