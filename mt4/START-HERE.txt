T-IOS MT4 Quick Setup

1. In T-IOS Settings, create your Deriv MT4 link and copy the one-time MT4 setup code.
2. Extract this ZIP and double-click Install-TIOS-MT4-Bridge.cmd. It finds the MT4 data folder, copies the bridge, and compiles it when MetaEditor is available.
3. In MT4, allow https://tmxosoyqflmwqzjgnkez.supabase.co under Tools > Options > Expert Advisors. Attach TradersEnvironmentBridge to a chart and paste the setup code into TE_Setup_Code.

Keep MT4 open while you want T-IOS to sync. The bridge is read-only and never asks for your MT4 password.

If setup cannot find the data folder, open the matching Deriv MT4 account and choose File > Open Data Folder once, then run the installer again.
